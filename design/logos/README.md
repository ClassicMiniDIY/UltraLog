# Logos

All marks are flattened SVG (wordmark outlined from Saira ExtraBold Italic), so they render anywhere without the font.

- `ultralog-lockup.svg`: mark + wordmark for dark grounds ("Ultra" `#f3f0ff`, "Log" magenta → orange → gold). Website nav, splash, Graphite exports.
- `ultralog-lockup-paper.svg`: for white grounds ("Ultra" `#15121f`, "Log" `#b8136a` → `#b5530f`). Paper exports, documents.
- `ultralog-lockup-mono-ink.svg`: single ink `#15121f`. One-colour print.
- `ultralog-mark.svg`: full-colour mark on its own dark fill. Favicon, avatar, About.
- `ultralog-mark-mono-ink.svg`: single ink `#15121f`, no fill. Light grounds, embossing.
- `ultralog-mark-mono-white.svg`: single ink `#f3f0ff`, no fill. Dark photos, engraving.
- `ultralog-app-icon.svg`, `ultralog-app-icon-1024.png`: app icon master (1024, rounded tile radius 228). Generate .icns / .ico from the PNG.
- `ultralog-badge.png`: the original neon badge, transparent background. Merch and legacy; not the primary logo. Dark grounds only.
