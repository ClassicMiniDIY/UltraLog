# ActivityRail

The 48px vertical bar on the far left that switches the side panel: Files, Properties, Tools, then Settings pinned to the bottom.

Icons are 20px outline at `ink-subtle`; hover `ink` on `bg-hover`; active `cyan` on `cyan-soft` with a 2px cyan indicator at the rail's left edge. Every button has a tooltip with the panel name. Keep it to four or five destinations.
