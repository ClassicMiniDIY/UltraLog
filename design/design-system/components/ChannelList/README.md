# ChannelList

The searchable channel picker in the Properties panel: search, a "Selected 4 / 10" count, collapsible groups ("With data · 90"), and one row per channel with checkbox, name, assigned series swatch and unit.

Checked rows get `bg-active` and show their series swatch, so the list, the cards and the plot legend all agree on colour. Units are mono `ink-subtle`. When ten channels are selected, further checkboxes disable with a caption explaining the limit.
