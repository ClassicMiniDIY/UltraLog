# ExportSheet

The page layout of an exported PDF or PNG: lockup, title, time range and record stats, the chart, a legend with every series, and a footer with ultralog.co, version and export date.

Rendered in the `paper` theme (white page, ink type, `ultralog-lockup-paper`) or `graphite` (grey page, light type, `ultralog-lockup`). The 2px sunset redline runs along the top edge. Both use the Okabe-Ito series, cividis maps and blue/orange diverging map, with series 9-10 dashed, because exports leave the app and the reader's colour vision is unknown. Graphite keeps a white paper margin in PDFs so a printed page never floods with ink.
