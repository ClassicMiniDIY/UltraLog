# DropZone

The welcome / empty state of the Files panel: drop target plus file picker.

A dashed `line-control` border on `bg-panel` with a faint perspective grid rising from the bottom edge (the synthwave floor from the brand art, drawn in `line`). The title is `headline`-style Saira italic; the one primary button is "Select a file"; supported extensions are listed in mono. While a file is dragged over it, the border goes solid `cyan` on `cyan-soft`.
