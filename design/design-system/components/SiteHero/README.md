# SiteHero

The ultralog.co hero: nav with the lockup, an eyebrow line, the `display` headline with one word in `magenta`, a one-sentence lede, the OS-detected primary download plus a secondary docs link, and the version in mono.

Background `bg-void`, the striped sunset (from the cover geometry) top-right, and the perspective floor in `grid-floor` along the bottom edge. One hero per page. Follows the visitor's Ultra intensity if the site offers the toggle; defaults to Night Drive.
