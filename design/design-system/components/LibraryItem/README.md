# LibraryItem

A saved computed-channel template in Your Library: a magenta italic ƒ, the name, its unit, a gold favourite star, the formula in mono, and Apply / more actions.

The ƒ in `magenta` is the system-wide mark of a computed (virtual) channel; use it wherever a computed channel appears (channel list, legend, file stats). Consumer provides: name, unit, formula, favourite, apply handler.
