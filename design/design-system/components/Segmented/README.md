# Segmented

A mutually exclusive choice of 2-5 short options shown at once: Plot mode (Single / Stacked), Histogram mode (Hit count / Average Z), Font size (S M L XL), Load axis (MAP / TPS).

The active segment is `cyan-soft` with `cyan` text and a 1px cyan inset; others are `ink-muted` on `bg-field`. Labels are sentence case or short abbreviations. More than five options, or options longer than two words: use a select.
