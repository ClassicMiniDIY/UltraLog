# ExportDialog

Choose format (PDF / PNG) and export theme before saving a chart or table.

Two visual radio cards with live thumbnails: **Paper** (default, selected) and **Graphite**. Thumbnails render with `data-theme="paper"` / `"graphite"` so they are honest previews. An info notice states that exports always use the color-blind safe palette. One primary action labelled with the format ("Export PDF"). Remember the last choice per format.
