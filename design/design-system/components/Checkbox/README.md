# Checkbox

Toggles a setting on or off: Color blind mode, Cursor tracking, Scroll to zoom, Show grid, Field normalization, Blank low-confidence cells.

16px box, `line-control` border on `bg-field`; checked fills `cyan` with an `on-cyan` check. The label is `ink` 13px; an optional caption sits under it, indented to the label, in `ink-subtle`. Disabled uses `ink-disabled` and says why in the caption when the reason isn't obvious.
