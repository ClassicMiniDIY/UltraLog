# IntensityControl

The **Ultra intensity** setting: one slider, 0-100, that sets how much neon the app wears. Default 35 (Night Drive).

Detents and labels at 0 Stealth, 35 Night Drive, 70 Neon, 100 Ultra; the current name and number sit top-right in Saira italic `cyan`. The track itself previews the dial: grey `line-control` into the sunset `redline-*` stops. Show the caption "Never changes your data colours or text contrast." Disabled (locked at the High contrast values) while High contrast is on, with that reason in the caption. See *Ultra intensity* for what each level changes.
