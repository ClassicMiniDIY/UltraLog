# PlaybackBar

Transport controls along the bottom of every time-based view: play/pause, stop, speed, the current time, the record counter, and the scrubber.

Play is the one cyan-filled transport button; the time readout is `data-lg` in `cyan`, matching the plot cursor so the two read as one thing. The record counter groups thousands with a thin space ("40 301 / 223 559"). The scrubber thumb is an `ink` bar 18px tall; start and end times sit at the track ends in `data-sm`.
