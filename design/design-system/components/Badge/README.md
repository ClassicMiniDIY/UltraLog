# Badge

Small labels: ECU source (mono, outlined), computed-channel ƒ, status (always icon + word), version, counts.

Status badges use the `*-soft` fill with the status colour; the icon shape carries the meaning too (check = success, triangle = warning, octagon = danger, circle-i = info). Event-count badges (`ul-count`) encode confidence by fill style: filled high, outlined medium, dashed low.
