# ModeNav

The app's top-level workspace switch: Log Viewer, Scatter Plots, Histogram, Lambda Delay, Accel Enrichment.

Set in the `overline` style (Saira 600, uppercase, 0.08em) with a 16px icon. The active item is `cyan` with a 2px cyan bar on the bottom edge carrying `glow-cyan`; the only glow in the chrome besides the primary button hover. Sits on `bg-panel` directly under the native menu bar. Consumer provides: items (icon + label), active id. New analysis tools that are a full workspace get a mode; anything that is a panel or dialog does not.
